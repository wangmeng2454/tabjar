## 一、这是什么

**TabJar（标签罐）** —— 一个面向**华为浏览器（PC 版）**的标签页收纳扩展：
点一下，把所有标签页收进一个清爽的列表、立刻释放内存；随时一键找回。
基于 **Manifest V3 + TypeScript + Vite**，同时兼容 Chrome / Edge。

**当前状态**：v1.0 MVP 功能已实现，配套**开发前置资料（本 docs 目录）**已产出。

---

## 二、核心价值

| 痛点 | 解法 |
|---|---|
| 标签太多、内存暴涨、系统卡顿 | 一键收纳为列表，内存最多降 ~95% |
| 关标签怕丢页面 | 收纳后可搜索、可恢复、可撤销、可导出备份 |
| 竞品英文/需付费/要上云 | 中文优先、免费、本地优先、隐私安全 |

## 四、项目结构

```
tabjar/
├── manifest.config.ts      # 扩展清单（TS 定义，构建时生成 manifest.json）
├── vite.config.ts          # 构建配置
├── tsconfig.json
├── package.json
├── public/icons/           # 图标 16/32/48/128
├── src/
│   ├── types.ts            # 数据模型（TabRecord / TabGroup / Settings）
│   ├── utils.ts            # 纯工具函数
│   ├── dom.ts              # DOM 小工具
│   ├── storage.ts          # chrome.storage 读写 + 数据迁移
│   ├── serialize.ts        # 导入 / 导出
│   ├── background.ts       # Service Worker（采集/落盘/关标签/菜单/快捷键）
│   └── tabs/               # 汇总列表页（html/ts/css）
├── tools/generate-icons.py # 图标生成脚本
├── docs/                   # ← 本套前置资料（00~10）
└── dist/                   # 构建产物（在浏览器中加载此目录）
```

## 五、快速开始

### 开发
```powershell
npm install        # 安装依赖
npm run build      # 构建到 dist/
npm run watch      # 监听改动自动重建
npm run typecheck  # 类型检查
```

### 在华为浏览器加载
1. `npm run build`
2. 华为浏览器 → `chrome://extensions`（或 菜单 → 管理扩展程序）
3. 打开右上角 **开发者模式**
4. 点 **加载已解压的扩展程序** → 选择本项目 **`dist/`** 目录

### 使用
- 点工具栏 TabJar 图标（或 `Ctrl+Shift+E`）→ 当前窗口所有标签被收纳并关闭
- 汇总页：搜索 / 恢复单条 / 恢复整组 / 重命名 / 星标 / 批量 / 导入导出 / 撤销

## 六、关键结论摘要

1. **做 OneTab 的心智 + TabXpert 的组织力，不做 Workona/AI/云**（详见 03）。
2. **本地优先、隐私安全、中文、免费、轻量**是我们的差异化（详见 01/03）。
3. **华为浏览器技术与 Chrome 同源**，难点在上架合规而非技术（详见 07）。
4. **「先落盘后关标签」是数据安全铁律**，务必在所有相关代码中遵守（详见 04/05/10）。
