# 测试计划与验收标准

> 文档版本：v1.0 ｜ 更新日期：2026-10-07
> 关联：[需求分析](./02-需求分析文档(PRD).md) · [华为浏览器适配](./07-华为浏览器适配与发布指南.md)

---

## 1. 测试目标

验证 TabJar 扩展在**华为浏览器 PC（主）、Chrome、Edge** 上，核心功能正确、数据不丢、主题适配、无崩溃/无报错。

---

## 2. 测试范围

| 类型 | 内容 |
|---|---|
| 功能测试 | 收纳、恢复、删除、撤销、搜索、重命名、星标、批量、导入导出、设置 |
| 兼容性测试 | 华为 / Chrome / Edge × 深浅色 × 多窗口 |
| 数据测试 | 持久化、迁移、去重、边界（空列表、海量标签） |
| 性能测试 | 收纳/恢复耗时、列表页滚动流畅度 |
| 安全测试 | 权限、XSS、异常 URL 过滤 |
| 异常测试 | SW 回收、窗口关闭、存储超限 |

---

## 3. 测试用例

### 3.1 收纳与入口（TC-C）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-C-01 | 开 5 个普通网页，点图标 | 全部收进 1 组，标签关闭，列表页打开 |
| TC-C-02 | 用 Ctrl+Shift+E | 同 TC-C-01 |
| TC-C-03 | 某页右键→收纳当前标签页 | 仅该页入列表 |
| TC-C-04 | 某页右键→收纳其余标签页 | 保留当前页，其余入列表 |
| TC-C-05 | 窗口含固定标签页（设置=忽略固定页） | 固定页不收 |
| TC-C-06 | 窗口含 `chrome://settings` 等内部页 | 内部页不收 |
| TC-C-07 | 列表中已存在某 URL，再次收纳 | 开启去重则不重复存储 |
| TC-C-08 | 同批出现重复 URL | 只保留一条 |
| TC-C-09 | 全部标签都不可收纳 | 不建空组，打开列表页 |
| TC-C-10 | 收纳瞬间断网/大页面 | 数据已落盘，标签关闭，无丢失 |
| TC-C-11 | 某页右键→打开 TabJar 列表 | 列表页被打开；若已开着则切换到它并前置窗口 |

### 3.2 恢复与删除（TC-R）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-R-01 | 点条目标题 | 新开该页并从列表移除 |
| TC-R-02 | 点「恢复整组」 | 组内全部打开，组从列表移除 |
| TC-R-03 | 点「全部恢复」 | 所有页面打开，列表清空 |
| TC-R-04 | 点条目 × | 仅移除记录，不打开页面 |
| TC-R-05 | 删组 | 该组及其选中项一并清除 |
| TC-R-06 | 清空 | 二次确认后清空 |
| TC-R-07 | 恢复整组时开启「新窗口打开」 | 在新窗口打开 |
| TC-R-08 | 恢复后组内无剩余条目 | 该组自动消失 |

### 3.3 撤销（TC-U）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-U-01 | 收纳后点「撤销收纳」 | 标签回到原窗口，组消失 |
| TC-U-02 | 收纳后关闭原窗口再撤销 | 退化为在窗口打开，不报错 |
| TC-U-03 | 无收纳操作 | 「撤销收纳」按钮不显示 |

### 3.4 组织与搜索（TC-O）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-O-01 | 搜索关键词命中标题 | 只显示命中条目 |
| TC-O-02 | 关键词命中分组名 | 整组显示 |
| TC-O-03 | 关键词无命中 | 显示「没有匹配的标签页。」 |
| TC-O-04 | 修改分组名 | Enter 保存，Esc 取消 |
| TC-O-05 | 组名改为空白 | 回退默认名 |
| TC-O-06 | 点星标 | 组置顶，样式变化 |
| TC-O-07 | 全选分组 + 删除所选 | 组内条目删除，空组消失 |
| TC-O-08 | 选中多项 + 合并为新组 | 条目抽出合并，插到最前 |
| TC-O-09 | 点分组头的**折叠箭头** | 该组条目收起，仅留分组头（组名 + 收纳时间 + 条数）；箭头方向随之改变，`aria-expanded` 同步为 `false` |
| TC-O-10 | 折叠若干组后刷新列表页 / 关闭标签重开列表页 | **折叠状态保持**（`chrome.storage.local` 的 `collapsed` 生效），不再回到全展开 |
| TC-O-11 | 折叠某组后，在搜索框输入命中该组的关键词 | 该组**自动展开**并显示匹配条目（不得出现"搜到了却看不见"）；清空搜索框 → 恢复原折叠状态 |
| TC-O-12 | 折叠某组后，点该组头的「全选本组」 | 组内**全部**条目被选中（**含被折叠隐藏的**），批量栏计数 = 该组条数 |
| TC-O-13 | 删除一个处于折叠状态的分组 | 无报错；`collapsed` 中该组 id 被清理，不再残留孤儿 id |

### 3.5 导入导出（TC-I）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-I-01 | 导出 JSON | 文件下载，结构含 version/groups |
| TC-I-02 | 导出 HTML | 可被浏览器「导入书签」识别 |
| TC-I-03 | 导出 TXT | 纯链接清单 |
| TC-I-04 | 导入本扩展的 JSON | 各组插到列表最前，**分组结构完整保留**（见 TC-I-07） |
| TC-I-05 | 导入纯文本链接 | 提取链接成为新分组 |
| TC-I-06 | 导入非法文件 | 提示「没有解析到任何网址」，不崩溃 |
| TC-I-07 | **导出 → 清空 → 导入**（3 组，其中 1 组已星标、组名自定义、条目带 `favIconUrl`） | 导入后仍是 **3 组**，**组名 / 星标 / 图标 / 条数逐项一致**（回归 TK-907：修复前会合并成 1 组、图标全丢） |
| TC-I-08 | 粘贴 **OneTab 文本**（`网址 \| 标题`，URL 在前）导入，含 `https://www.bilibili.com/read/cv26890211/?spm_id_from=333.999.0.0 \| 博德之门3 职业大全最终修订版文字版 - 哔哩哔哩` | 每条**标题正确**（显示文章名而非只剩 `www.bilibili.com`）（TK-311：修复前右侧标题被丢弃） |
| TC-I-09 | 分隔符变体：全角 `｜`、TAB 分隔的「网址｜标题」行 | 均正确提取标题；**URL 不含分隔符残渣**（TK-311：修复前全角 `｜` 会被吞进 URL） |
| TC-I-10 | 一行内含两个 URL | 生成两条记录，各自按域名兜底，标题不串行 |
| TC-I-11 | 混合批：`标题 \| 网址` 与 `网址 \| 标题` 两种行混在同一文本导入 | 各按所在行格式正确解析，互不干扰 |

### 3.6 主题与界面（TC-T）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-T-01 | 设为深色 | 界面深色，文字清晰 |
| TC-T-02 | 设为浅色 | 界面浅色 |
| TC-T-03 | 设为跟随系统并切换系统主题 | 实时跟随 |
| TC-T-04 | 空列表 | 显示空状态引导 |
| TC-T-05 | 徽标 | 数字等于已收纳总数 |
| TC-T-06 | **浮层开合与互斥**：刚打开列表页时，设置面板 / 导出菜单 / 批量栏应为**不可见**；点「导出」展开、再点收起、点浮层外收起；点「设置」展开且**自动关掉导出菜单**（反之亦然）；勾选条目后批量栏出现，点「取消」消失 | **三处浮层默认隐藏**，开合与互斥均正确（回归 TK-906：修复前它们从加载起就一直显示，按钮"点了没反应"） |
| TC-T-07 | **条目标题两行截断**（F-3.10）：找一条超长标题条目观察 | 最多两行、超出部分省略号；短标题一行且行高不空撑；域名胶囊与删除按钮仍垂直居中；标题兜底为长 URL 时可折行不破版（TK-213）；**附加检查点（TK-214）**：悬停条目标题，气泡**第一行为完整标题、第二行为完整 URL**（两行换行显示）；标题等于 URL 的条目气泡只显示一行 |

### 3.7 数据与持久化（TC-D）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-D-01 | 关闭浏览器重开 | 列表数据仍在 |
| TC-D-02 | 注入旧版（缺 name/starred）数据 | 读取时自动补齐 |
| TC-D-03 | 存储中塞入畸形数据 | 读取不崩溃，过滤非法项 |
| TC-D-04 | 收纳 500 条 | 列表可流畅滚动，操作无卡顿 |

### 3.8 安全（TC-S）
| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-S-01 | 页面标题含 `<script>` 等 | 以纯文本显示，不执行 |

| TC-S-03 | 检查权限 | 仅 tabs/storage/contextMenus |

## 5. 性能指标

| 指标 | 目标 |
|---|---|
| 收纳 30 条耗时 | < 1s |
| 收纳/恢复 300 条 | < 2s |

| 空闲内存占用 | 可忽略（SW 不常驻） |
| 包体 | < 300 KB（不含图标） |

---

## 6. 验收标准（DoD）

1. 全部 P0 用例通过，P1 用例通过率 ≥ 95%。
2. 华为浏览器 PC 实测无阻塞性缺陷。
3. 无控制台报错；`npm run typecheck`、`npm run build` 均通过。
4. 数据在关闭/重开浏览器后完整保留。
5. 深色模式对比度达标。
6. 权限最小化，无网络请求。

---

## 7. 缺陷分级与处理

| 级别 | 定义 | 处理 |
|---|---|---|
| P0 致命 | 数据丢失、崩溃、无法加载 | 立即修复，阻塞发布 |
| P1 严重 | 核心功能不可用 | 本次迭代修复 |
| P2 一般 | 非核心功能异常/体验问题 | 排期修复 |
| P3 轻微 | 文案/样式瑕疵 | 择机修复 |

---

## 8. 测试环境

- 华为浏览器 PC 版（≥ 11.0.5.x）、Chrome、Edge 最新稳定版。
- Windows 10/11 64 位；深浅色系统各一轮。
- 加载方式：开发者模式加载 `dist/`。
- 数据准备：全新安装（空）、已有数据（迁移）、海量数据（500+ 条）三种起始状态。
