# 交互与视觉设计规范

> 文档版本：v1.0 ｜ 更新日期：2026-10-07
> 关联：[需求分析](./02-需求分析文档(PRD).md) · 源码：`src/tabs/tabs.html` / `src/tabs/tabs.css`

---

## 1. 设计原则

1. **零学习成本**：打开即用，主界面只暴露最高频动作。
2. **信息密度适中**：每条一行，图标+域名+标题三段式，扫读高效；**标题最多两行**截断（F-3.10），长标题信息量更大。
3. **渐进增强**：设置、导出等低频入口收起，用到再展开。
4. **一致与克制**：配色克制、动效少而轻，符合浏览器工具类产品气质。
5. **深浅双主题**：两套配色均满足对比度要求（华为审核硬指标）。

### 元素清单
| 区域 | 元素 | 交互 |
|---|---|---|
| 顶部 | 搜索框 | `input` 事件实时过滤 |
| 顶部 | 导入 / 导出 / 设置 | 点击展开浮层；点空白处收起 |
| 顶部 | 全部恢复 / 清空 | 清空需二次确认 |
| 摘要 | 组数/条数/估算内存 | 只读 |
| 分组头 | **折叠箭头（▾/▸）**、全选、星标、组名、时间、恢复整组、删除 | 箭头点击=折叠/展开；组名点击可改名 |
| 条目 | 复选、图标、域名、标题链接（最多两行截断，悬停显示标题全文）、删除× | 点击标题=恢复并移除 |
| 底部 | 批量操作栏 | 有选中项才显示 |

## 3. 交互流程

### 3.1 搜索
- 输入即过滤（无需回车）。
- 命中规则：**标签页标题/网址命中 → 只显示命中项**；若无命中但**分组名命中 → 显示整组**；都不命中 → 整组隐藏。
- 摘要文案切换为「匹配 X 组 / Y 条（共 Z 条）」。
- 无结果时显示「没有匹配的标签页。」

### 3.2 重命名
- 点击组名 → 原地变输入框 → **Enter/失焦保存**，**Esc 取消**。
- 输入空白 → 回退到默认名（不留空名）。
- 需防「失焦在 DOM 替换后重复提交」（用 `finished` 标记）。

### 3.3 星标
- 点击 ★/☆ → 切换 → **重新排序**（星标置顶）→ 落盘。

### 3.4 批量选择
- 单条复选 / 分组「全选」。
- 底部栏出现：「恢复所选」「合并为新组」「删除所选」「取消」。
- 删除时下标**从大到小**处理，防错位。

### 3.5 恢复
- 点条目标题 → 新开页面并从列表移除；组空则删组。
- 「恢复整组」→ 按设置开在当前/新窗口。
- 「全部恢复」→ 打开所有并清空列表。

### 3.6 撤销
- 收纳后有快照时，顶部显示「撤销收纳」；点击放回原窗口并删组；用完隐藏。

### 3.7 折叠 / 展开（F-3.8）
- **入口**：分组头**最左**的箭头按钮（`▾` 展开 / `▸` 折叠）。刻意**不与**已有交互重叠——
  复选框是「全选本组」、组名是「重命名」，都不兼作折叠开关，避免歧义点击。
- **折叠后**：隐藏该组全部条目，只留分组头；组名右侧的「收纳时间 · N 个」**照常显示**，
  所以折叠不会让人失去"这组有多大"的判断依据。
- **持久化**：折叠状态写入 `chrome.storage.local` 的 `collapsed`（组 id 列表），
  刷新页面 / 关闭重开列表页后**保持**。新收纳的组默认**展开**。
- **与搜索互斥（重要）**：搜索框非空时**强制展开**命中分组——否则"搜到了却看不见"会被当成 bug。
  清空搜索后自动回到原来的折叠状态。搜索态下箭头仍可点（只是改了状态，不影响当前显示）。
- **与批量选择的边界（重要）**：折叠**不改变**「全选本组」的范围，仍作用于组内**全部**条目（含被隐藏的）。
  折叠状态变化时**不清空**已勾选项（只有分组内容变化才清）。
- **无障碍**：箭头带 `aria-expanded`（展开 `true` / 折叠 `false`），`title` 为「折叠本组 / 展开本组」。
- ⚠️ **实现方式**：折叠时**不生成**条目 DOM（`render()` 是全量重建），不要写成「渲染后用 CSS 隐藏」——
  那会重新纠缠 `display` 与 `[hidden]` 的层叠优先级（TK-906 的教训）。
- 「全部折叠 / 全部展开」一键开关**一期不做**，已列入 backlog（`docs/02` §4.7）。

## 4. 视觉规范

### 4.1 色彩（CSS 变量，随 `data-theme` 切换）

| 语义 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#f5f6f8` | `#1b1d21` |
| 卡片 | `#ffffff` | `#26292e` |
| 主文字 | `#1a1a1a` | `#e8eaed` |
| 次文字 | `#6b7280` | `#9aa0a6` |
| 边框 | `#e3e5e9` | `#3a3d42` |
| 主色（品牌） | `#cf0a2c`（华为红系） | 同左 |
| 危险操作 | `#d93025` | `#ff6b6b` |
| 星标 | `#f5a623` | `#ffc14d` |

> ⚠️ 主题实现方式：在 `<html>` 上设 `data-theme="light|dark"`，CSS 用 `[data-theme='dark']` 覆盖变量。`auto` 模式监听 `prefers-color-scheme`。

### 4.2 字体
- 系统字体栈：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`
- 正文 14px；标题 15–16px 加粗；元信息 12px 次文字色。

### 4.3 间距与圆角
- 间距梯度：4 / 8 / 12 / 16 / 24 px。
- 卡片圆角 10px；按钮圆角 6px；输入框圆角 6px。
- 悬浮/选中态用浅色底 + 左侧主色竖条（可选）。

### 4.4 图标
- 站点图标 `16×16`（`favIconUrl`），加载失败回退「域名首字母」色块。
- 扩展图标尺寸：16/32/48/128 PNG。

### 4.5 无障碍
- 正文对比度 ≥ 4.5:1，大标题/图标 ≥ 3:1。
- 所有可点元素为原生 `<button>`/`<a>`/`<input>`，支持键盘 Tab 与 Enter。
- 删除/清空等破坏性操作有确认或撤销兜底。

## 5. 空状态与异常态

| 状态 | 呈现 |
|---|---|
| 无任何数据 | 「列表是空的。点击工具栏 TabJar 图标即可收纳当前窗口的标签页。」 |
| 搜索无结果 | 「没有匹配的标签页。」 |
| 图标加载失败 | 字母占位块 |
| 全部被去重过滤 | 不建空组，直接打开列表页 |
| 清空确认 | 原生 `confirm`「确定清空…此操作不可撤销。」 |

## 6. 微交互建议（二期）

- 收纳成功：图标/页面短暂的高亮或数字跳动动画。
- 恢复条目：条目淡出过渡。
- 拖拽排序（可选，需权衡复杂度）。
- 键盘导航：`j/k` 上下、`Enter` 恢复（可选）。
