# 竞品调研与功能总结

> 文档版本：v1.0 ｜ 更新日期：2026-10-07
> 调研范围：Chrome / Edge 商店中主流的「标签页收纳 / 会话管理」类扩展，重点关注 OneTab 及可运行在华为浏览器（Chromium 内核）上的同类产品。

---

## 1. 调研目的

1. 摸清「OneTab 类」产品的核心功能边界与用户价值。
2. 找出各竞品的功能差异、技术路线（**收纳式** vs **挂起式** vs **看板式**）。
3. 为自研「TabJar（标签罐）」插件提供功能取舍依据，明确「哪些必须做、哪些做差异化、哪些不做」。

## 3. 三类技术路线对比（关键结论）

这是选型的**第一性问题**：标签页「收纳」到底怎么做？

| 维度 | 收纳式（OneTab） | 挂起式（AutoTab Discard / ProTab） | 看板式（Toby / tabExtend） |
|---|---|---|---|
| 做法 | 记录 URL → 关闭标签 → 存列表 | 保留标签位置，卸载页面内存 | 保存为卡片，关闭或挂起 |
| 内存节省 | **最高（约 95%）** | 中（约 60~70%） | 取决于是否关闭 |
| 标签栏是否可见 | 否（进列表） | 是（置灰） | 否 |
| 恢复状态 | 重新加载（丢滚动/表单） | 点击即恢复 | 重新加载 |
| 恢复速度 | 慢（大批量时） | 中 | 快 |
| 适用人群 | 囤积症、要省内存 | 想快速找回 | 视觉型用户 |

**结论**：OneTab 的价值主张是「**极致省内存 + 零学习成本**」，用「牺牲标签栏可见性」换取「内存骤降」。自研产品应**以收纳式为主**，可借鉴挂起式作为可选的折中。

## 4. 竞品功能逐项拆解

### 4.1 OneTab（基准产品）
**核心功能**
- 一键把所有标签页收纳为一个列表并关闭，内存降低可达 95%。
- 分「组」（session）保存，按收纳批次分组。
- 单条 / 整组恢复；删除条目 / 清空列表。
- 分组命名、分享为网页（share as web page）。
- 固定标签页、扩展页面不收纳。
- 可选：锁定分组、暂停收纳（临时开关）。
- Pro：云备份（Google Drive）、跨设备。

**已知短板（用户吐槽集中点）**
- **只存 URL**，恢复即「全新加载」：丢失滚动位置、表单内容、登录态。
- **无云同步**（免费版），清缓存 / 换机即丢。
- 无搜索（v2 才加了列表页搜索）、无导出（社区版才有）。
- 大数据量时列表页极长、滚动卡顿。
- 无自动保存，误操作/崩溃可能丢失。

### 4.2 Better OneTab
- OneTab 的社区分叉，**深色模式 + 会话搜索 + JSON 导出 + 单条选择性恢复**。
- 内存受益与限制与 OneTab 基本相同。
- **可借鉴**：搜索、导出、深色模式、单条恢复。

### 4.3 Session Buddy
- 自动保存会话快照，**崩溃/重启后可恢复**。
- **强大会话搜索**，可查看任意历史时间点的浏览状态。
- 局限：无云同步、界面偏复杂。
- **可借鉴**：自动备份、历史会话检索。

### 4.4 Tab Manager Plus
- 仪表盘式总览：搜索（模糊匹配）、**重复标签检测**、按窗口分组、批量关闭。
- 局限：仅英文、无云同步、**几乎不省内存**（标签未关闭）。
- **可借鉴**：模糊搜索、重复检测。

### 4.5 Workona
- **工作区（Workspace）** 概念：一个项目 = 一组标签 + 书签 + 笔记 + 文档。
- 团队协作、共享工作区、Google 官方推荐。
- 局限：高级功能付费、学习曲线陡。
- **可借鉴**：项目化分组、分组备注。

### 4.6 Toby
- **可视化看板**：新标签页变成收藏夹网格，拖拽整理。
- 有移动端 App、集合共享。
- 局限：体积大、免费版上限 60 条、评分相对低。
- **可借鉴**：可视化、拖拽（不适合作为主交互，可作增强）。

### 4.7 Tabs Outliner
- **树状视图**：保留标签间的父子跳转关系，支持给标签加备注。
- 局限：界面老旧、学习曲线陡。
- **可借鉴**：树状层级、备注（进阶功能）。

### 4.8 Tab Wrangler
- **自动断舍离**：N 分钟不活跃自动关闭，进 "Tab Corral" 可恢复。
- 高度可配置的规则、白名单。
- 局限：可能误关、需调规则。
- **可借鉴**：自动收纳规则、白名单。

### 4.9 tabExtend
- 看板式新标签页 + **页面提醒**功能。
- 局限：免费版限 30 条。

### 4.10 TabXpert（最完整的参考）
- **自动保存会话**（含版本历史）、标签组、书签三合一。
- 弹窗 / 标签页 / 窗口 / **侧边栏（垂直标签）** 四种界面。
- 标签 / 会话 / 书签**全局搜索**、标签（tag）组织。
- **挂起式打开**（省内存 + 快恢复）。
- **从 OneTab / Session Buddy / Workona / Toby 导入**。
- 本地优先 + 可选云同步（Pro）。
- 局限：无免费版（仅 14 天试用）、无工作区、需付费。

## 6. 竞品核心痛点（= 我们的机会点）

1. **恢复丢状态**：OneTab 家族只存 URL，滚动/表单/登录态全丢。
   → 机会：至少提供「挂起式恢复」作为可选，或记录更多元数据。
2. **数据易丢**：无云同步、无自动备份，清缓存即全丢。
   → 机会：本地自动快照 + 可导出 JSON 作为「自助备份」。
3. **功能单一 or 过度复杂**：OneTab 太简、Workona/TabXpert 太重且贵。
   → 机会：**「简单默认 + 渐进增强」**——默认一键收纳，进阶项折叠在设置里。
4. **无本地化**：多数英文界面、时区/语言不适配。
   → 机会：**中文优先**，贴合国内浏览器生态。
5. **隐私顾虑**：云同步意味着把浏览数据交给第三方。
   → 机会：**本地优先、默认不上云**，数据主权归用户。

---

## 7. 调研结论

1. 「一键收纳 + 列表恢复」是被 200 万+ 用户验证过的**核心刚需**，必须作为产品基座。
2. 竞品普遍在「**组织能力（搜索/分组/命名）**」与「**数据安全（备份/恢复状态）**」上有短板，这是差异化空间。
3. 云同步、AI、工作区属于「锦上添花」，且多与付费/隐私冲突，**一期不做**。
4. 面向华为浏览器，最有价值的是**本地化体验 + 隐私安全 + 轻量**，而非堆功能。
