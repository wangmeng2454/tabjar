## 1. 整合原则

1. **基座不变**：保留 OneTab 的核心心智——「一键收纳 + 列表恢复」，这是被 200 万用户验证的刚需。
2. **短板变长板**：竞品普遍弱在「组织能力」和「数据安全」，我们重点补这两块，且**默认免费、本地优先**。
3. **简单默认 + 渐进增强**：主界面只放 3 件事（收纳、搜索、恢复）；进阶项折叠进设置面板。
4. **本地优先、隐私优先**：默认零上传、零遥测。云同步、账号**一期不做**。
5. **中文优先**：界面/文案/时间格式全部为中文用户优化。

## 3. MoSCoW 优先级

### Must have（必须有 = MVP，已实现）
- 一键收纳全部标签 / 快捷键 / 右键菜单
- 分组存储、本地持久化
- 单条 / 整组 / 全部恢复、删除、清空
- 列表页展示（图标、域名、标题）
- 跳过扩展页与非可收纳页、忽略固定页
- 先落盘后关标签（防丢数据）

### Should have（应该有，已实现）
- 搜索过滤、分组重命名、星标置顶
- 批量选择（恢复/删除/合并）
- 撤销收纳、导入导出、深色模式
- 设置面板、徽标计数、空状态

### Could have（可以有 = 二期）
- 自动快照 / 自动备份 + 历史版本
- 自动收纳规则 + 白名单
- 挂起式恢复（保留滚动/表单）
- 侧边栏/垂直标签视图
- 模糊搜索、重复标签检测
- 分组备注、按域自动分组

### Won't have（本期不做）
- 云同步 / 账号体系
- AI 能力、团队协作
- 移动端

## 4. 差异化建议（面向华为浏览器）

### 4.1 产品差异化
| 方向 | 建议 | 对应竞品短板 |
|---|---|---|
| **组织力** | 强化搜索 + 星标 + 命名 + 批量，做「能收纳更能找」 | OneTab 只管收不管找 |
| **数据安全感** | 本地自动快照 + 一键导出 JSON，主打开放可迁移 | OneTab 清缓存即丢 |
| **隐私叙事** | 「数据只在你电脑上」作为卖点，权限最小化 | 付费竞品需上云 |
| **本地化** | 中文界面、`x月x日` 时间、贴合华为生态 | 多数竞品英文 |
| **轻量** | 包体小、零广告、零后台常驻 | Toby 24MB、广告类扩展 |

### 4.2 体验差异化
- **默认即爽**：安装后第一次点击就完成任务闭环，无需配置。
- **渐进增强**：设置面板默认收起，进阶项按需展开。
- **防误操作**：撤销收纳 + 清空二次确认，缓解「不敢用」心理。
- **状态可见**：徽标数字 + 「约可释放 X MB」给即时正反馈。

### 4.3 落地建议（按团队资源）
1. **先做精 MVP**：把「收纳-恢复-搜索」打磨到 0 bug，再谈增强。
2. **二期优先「数据安全」**：自动快照 + 历史版本，是最能建立信任的一步。
3. **二期再考虑挂起式**：技术收益大但风险高，需单独技术预研。
4. **暂不做云同步**：留好数据模型接口（序列化已就绪），未来可作为可选付费项接入，不破坏「本地优先」的定位。

## 6. 关键决策摘要

- **Q：抄 OneTab 还是做 Workona？** → 抄 OneTab 的**心智**，学 TabXpert 的**组织力**，但不做 Workspace/AI/云。
- **Q：要不要云同步？** → 一期不做。定位「本地优先、隐私安全」，用导出功能兜底数据迁移。
- **Q：竞品最大机会点？** → **「能收纳更能找」+「数据不丢」**，且中文、免费、轻量。
- **Q：华为浏览器特殊性？** → 内核同源、可直接用 Chrome 扩展技术；难点在**上架分发与合规**，不是技术（详见适配指南）。
