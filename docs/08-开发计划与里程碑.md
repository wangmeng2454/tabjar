## 1. 项目范围

- **交付物**：一款面向华为浏览器（PC）的标签页收纳扩展 **TabJar（标签罐）**（Manifest V3 + TypeScript）。
- **兼容目标**：华为浏览器 PC / Chrome / Edge。
- **当前状态**：**v1.0 MVP 已实现**（收纳、恢复、搜索、分组、批量、导入导出、深色、设置）。

---

## 2. 里程碑

| 里程碑 | 阶段 | 关键交付 | 状态 |
|---|---|---|---|
| **M0** | 立项与调研 | 竞品调研、需求分析、功能整合方案 | ✅ 完成 |
| **M1** | 技术设计 | 技术方案、数据模型、UI 规范、适配指南 | ✅ 完成 |
| **M2** | MVP 实现 | 收纳/恢复/搜索/分组/批量/导入导出/深色 | ✅ 完成 |
| **M3** | 联调与测试 | 华为浏览器实测、用例回归、缺陷修复 | ⏳ 待办 |
| **M4** | v1.0 发布 | 打包、分发/上架、文档交付 | ⏳ 待办 |
| **M5** | v1.1 迭代 | 自动快照、性能优化、错误兜底 | ⏳ 规划中 |
| **M6** | v1.2 / v2.0 | 组织增强、侧边栏、自动收纳规则 | ⏳ 规划中 |

## 5. 分工建议（若为多人）

| 角色 | 职责 |
|---|---|
| 产品 | 需求、竞品、优先级、验收 |
| 前端/扩展开发 | 功能实现、构建、打包 |
| 测试 | 用例设计、兼容性实测、回归 |
| 设计 | UI/UX 规范、图标、截图 |
| 运营/发布 | 上架材料、隐私政策、渠道提交 |

> 单人开发时，建议**先保 MVP 稳定，再谈增强**，不追求功能数量。
